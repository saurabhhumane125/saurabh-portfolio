# Project screenshots

The `trove-showcase.png` and `tradox-showcase.png` assets are composed presentations based on the images supplied in chat. See `ASSETS.md` for provenance and prompts. They are not original screenshot files.

Original screenshots can also be added here using the names below. PNG, JPG/JPEG, and WebP extensions are supported. The project galleries detect the assets at build time; no code changes are needed when adding or replacing them.

| File stem | Screenshot |
| --- | --- |
| `trove-dashboard` | Trove home screen with vault summary, storage usage, and recent documents |
| `trove-family` | Trove family member selection screen |
| `trove-splash` | Trove lock icon, title, build date, and tagline |
| `tradox-overview` | Tradox overview with signal watch and news wire |
| `tradox-stock` | Tradox RELIANCE stock research and candlestick chart |
| `tradox-launch` | Tradox title and “Clarity before every trade” launch screen |

Use the originals without changing their interface text, numbers, or labels. Trove images retain their portrait aspect ratio; Tradox screenshots retain their landscape aspect ratio. The existing concept illustrations remain visible until screenshot files are available.
